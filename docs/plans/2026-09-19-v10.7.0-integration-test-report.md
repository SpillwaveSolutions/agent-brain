# v10.7.0 integration test report

Date: 2026-09-19. Branch: `chore/v10.7-integration-test-and-host-parity`.

## Result

Agent Brain 10.7.0 works end to end on a local Ollama stack, with three product defects found and fixed on this branch and five more filed as issues. Index, hybrid, BM25, vector, and multi search all returned the expected file on the first try. Graph mode, `mcp start`, and UDS transport did not work in the released wheels.

## Defects fixed on this branch

1. **`mcp start` spawned a module with no entry point.** `agent-brain-cli` runs `python -m agent_brain_mcp`. The package had no `__main__.py`. The unit test mocked the spawn, so it never caught this. Fix: `agent-brain-mcp/agent_brain_mcp/__main__.py` plus a subprocess test.
2. **Parent process never opened the graph store.** Since the Phase 64 isolated child build, the child persisted the graph and the parent kept `initialized: false`. Fix: `GraphIndexManager.refresh_store()` after each build, and lazy `initialize()` in `query()`.
3. **Triplet read used the wrong LlamaIndex call.** `SimplePropertyGraphStore.get_triplets()` returns nothing without a filter in llama-index-core 0.14.24, and its tuples have no `subject` attribute. Fix: `_store_triplets()` reads `graph.relations` and normalizes all three store shapes.

## Issue #236

Not reproducible. Six-case `pip` matrix on Python 3.10.14, comment posted on the issue with the results and a close date of 2026-10-03. New issue #249 tracks `mcp` 2.x support, since any environment with `mcp>=2` cannot co-install the MCP package.

## How to repeat

1. Build the four wheels with `poetry build` in each package directory.
2. Install them into a clean venv with `uv pip install`.
3. From `e2e/sample-project/`, write `.agent-brain/config.yaml` with the Ollama providers above, then run `agent-brain init --path .` and `agent-brain start`.
4. Run the steps in the table. Every query names its expected file.
5. Finish with `agent-brain reset --yes`, `agent-brain mcp stop`, and `agent-brain stop`.
